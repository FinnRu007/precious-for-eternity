# Seite pflegen

| Was ändern | Wo |
|---|---|
| Neuer Wurf, neuer Hund | `data.js` – eine Zeile kopieren und den Text ändern |
| Kontaktdaten, Texte | `index.html` – Text zwischen den Tags ändern |
| Foto tauschen | neues Bild in `img/` legen (gleicher Name) oder in `index.html` den Dateinamen anpassen |
| Impressum | `impressum.html` |

Keine Programme nötig: Auf GitHub die Datei öffnen, Stift-Symbol, ändern, „Commit changes“. Nach 1–2 Minuten ist die Änderung online.
